### What I'm building

- **[FORKSAI](https://forksai.app)**, an AI study platform where students turn their notes and PDFs into flashcards, mock exams and lessons from an AI tutor
- **An LLM orchestration backend that improves output quality**: long tasks are split into parts and generated in parallel, every result is checked, and weak or malformed output is retried or rejected before a student sees it
- **A cost-efficient backend for LLM requests**: work is divided into blocks, results are cached so the same work is never paid for twice, each task goes to the cheapest model that can handle it, and requests fall back to a second provider instead of failing
- **A self-learning study algorithm** that models how well each student remembers each card and schedules their next review from their own answers
- **An AI tutor** that teaches a student's own material out loud on a live whiteboard and checks understanding as it goes
- **An Android app** built from the same codebase, with offline study that syncs when the phone is back online
